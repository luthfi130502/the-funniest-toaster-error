An entry for the make.fun bounty [The Funniest Toaster Error Message](https://make.fun/bounty/u-eager-stork-81-9647-the-funniest-toaster-error-436406cd).

A small kitchen toaster keeps a deadpan incident log, and this is the line it
shows its owner when breakfast does not go to plan:

> The bread entered at 07:12. What rose at 07:15 was not the bread.

No puns, no panic — just a quiet, dramatic note from an appliance that has
seen something it cannot explain.

## Run it

Requires Node 22 or later:

```sh
node main.ts
```

The program writes its single line (65 characters, inside the 1–120 gate) to
`/output/entry.txt` and checks the length before writing.
